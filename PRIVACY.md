# FridayV8 Privacy Policy

FridayV8 uses account login so users can save and view their own command history later.

## What is saved

FridayV8 may save:

- User email
- User name
- Hashed password
- Command history created inside FridayV8
- Safety alerts for blocked unsafe commands
- Owner/admin audit logs

## What is not secretly collected

FridayV8 does not secretly collect or upload:

- Passwords in plain text
- Personal files
- WhatsApp messages
- Browser history
- Private chats outside FridayV8
- Screen recordings
- Keyboard typing outside FridayV8

## Owner/Author controls

The Owner/Author dashboard can view app usage summaries, users, safety events, maintenance mode, and suspend/unsuspend users. Owner actions are logged.

## Security

Passwords are hashed. Login uses JWT tokens. Owner actions are audited. Use HTTPS and a strong secret key before public deployment.
