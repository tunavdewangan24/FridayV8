FRIDAY FAST WAKE LISTENER

This adds:
- Say "hello friday" to open Friday Fast Voice Mode
- Double clap to open Friday Fast Voice Mode
- Optional Windows startup auto-listener

IMPORTANT:
Friday cannot hear "hello friday" when nothing is running.
So START_FRIDAY_FAST_WAKE.bat must be running in background.
For auto-start, run INSTALL_FRIDAY_FAST_WAKE_STARTUP.bat.

Install:
1. Copy all files to C:\FridayV8
2. Make sure FRIDAY_FAST_MODE.py is already in C:\FridayV8
3. Run FRIDAY_FAST_MODE.py once -> option 3 -> setup mic
   Recommended:
   Laptop mic: 2 or 28
   Noise TWO Bluetooth: 30 or 31
4. Run START_FRIDAY_FAST_WAKE.bat
5. Say: hello friday

Files:
- FRIDAY_FAST_WAKE.py
- START_FRIDAY_FAST_WAKE.bat
- START_FRIDAY_FAST_VOICE.bat
- INSTALL_FRIDAY_FAST_WAKE_STARTUP.bat
- REMOVE_FRIDAY_FAST_WAKE_STARTUP.bat

Auto-start:
Run:
INSTALL_FRIDAY_FAST_WAKE_STARTUP.bat

Remove auto-start:
Run:
REMOVE_FRIDAY_FAST_WAKE_STARTUP.bat
