FRIDAY V8 MULTITASKING CONTROL
==============================

FIRST TIME ONLY:
1. Double-click INSTALL
2. Double-click SELECT_MIC
3. Choose the mic that worked earlier, usually 2
4. Double-click MIC_TEST
5. Double-click START_FRIDAY

DAILY USE:
- Double-click START_FRIDAY only.

MOST IMPORTANT MULTITASKING COMMANDS:
- switch to chrome
- bring whatsapp to front
- restore chrome
- list open windows
- restore all windows
- show desktop
- minimize current window
- maximize current window
- close current window
- next tab
- previous tab
- find tab youtube
- search this tab python tutorial
- open new tab and search ai projects

NOTE ABOUT BROWSER TABS:
Windows can easily restore minimized WINDOWS like Chrome or WhatsApp.
Individual browser tabs are inside Chrome/Edge, so FRIDAY controls them using shortcuts:
next tab, previous tab, find tab <name>, close tab, reopen closed tab.
