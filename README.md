# FRIDAY Fast Mode

FRIDAY Fast Mode is a Windows desktop automation assistant focused on speed, multitasking, and voice commands.

## Features
- Fast commands: yt, g, wa, tabs, next, prev, back, min, restore
- Same-tab browser search
- WhatsApp safe message flow
- Voice mode
- Wake listener: "hello friday"
- Double clap wake support
- No random option menu
- Clear command = execute
- Unclear command = ignored and answer properly
